# FeastFlow 🍕

> Delicious Food, Delivered. A modern, responsive food ordering web application.

## 🌟 Features

- **Restaurant & Menu Browsing**: Explore a curated list of dishes, cuisines, and restaurants.
- **Interactive Cart & Checkout**: Real-time cart calculations, add/remove items, and order summary.
- **Search & Filtering**: Fast dynamic search across restaurants and menu items.
- **User Authentication**: Sign in and manage profiles.
- **Order Tracking**: Keep track of order history and status.
- **Dark / Light Theme**: Built-in theme toggle for day and night modes.
- **Fully Responsive**: Optimized for desktop, tablet, and mobile browsers.

## 🚀 Getting Started

Simply open `index.html` in your favorite web browser or serve it using any local HTTP server:

```bash
# Using Python
python -m http.server 8000

# Using Node.js (npx serve)
npx serve .
```

Then visit `http://localhost:8000` in your browser.
